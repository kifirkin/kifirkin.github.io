02 The harnessСреда

A small core, an open surfaceМалое ядро, открытая поверхность

pi is a minimal terminal coding agent: a session loop and a handful of built-in tools, designed so that everything else arrives as an extension. Braid is one of those extensions, and a large one.pi — минимальный терминальный кодинг-агент: цикл сессии и несколько встроенных инструментов, устроенный так, что всё остальное приходит расширениями. Braid — одно из таких расширений, и немаленькое.

Nine native toolsДевять нативных инструментов

read, write, edit, and bash sit at the center; grep, find, ls, and PowerShell round out the working set. tool_search returns deferred tools to the active list when they are needed.read, write, edit и bash — в центре; grep, find, ls и PowerShell дополняют рабочий набор. tool_search возвращает отложенные инструменты в активный список, когда они нужны.

Sessions are treesСессии — это деревья

Every turn is a node in a JSON Lines (JSONL) session file. Branch, fork, resume, and compact in place, without losing the trail that led there.Каждый шаг — узел в файле сессии JSON Lines (JSONL). Ветвление, форки, возобновление и сжатие на месте — тропа, которая привела сюда, не теряется.

Four ways in, one loopЧетыре входа, один цикл

An interactive terminal user interface (TUI), a one-shot --print, machine-readable JSON, or Remote Procedure Call (RPC) over standard input and output. A Software Development Kit (SDK) embeds the same loop in your own programs.Интерактивный терминальный интерфейс (TUI), одноразовый --print, машиночитаемый JSON или RPC (Remote Procedure Call) поверх стандартного ввода-вывода. SDK (Software Development Kit) встраивает тот же цикл в ваши программы.

Extensible by designРасширяемость по замыслу

Extensions are TypeScript modules, skills are Markdown procedures, and prompts and themes are plain files. Bundles ship as pi packages.Расширения — TypeScript-модули, навыки — Markdown-процедуры, промпты и темы — простые файлы. Собираются в pi-пакеты.

This build ran against pi 1.1.0. Native tool inventory: packages/core/TOOLS.md.Сборка выполнена на pi 1.1.0. Каталог нативных инструментов: packages/core/TOOLS.md.

03 PhilosophyФилософия

The shape of “No”Форма слова «нет»

pi's core says no on purpose: each no is a door an extension can walk through, and the answer is allowed to move. One of the doors below has already opened.Ядро pi говорит «нет» намеренно: каждое «нет» — дверь, в которую может войти расширение, и ответу позволено меняться. Одна из дверей ниже уже открылась.

06 ArchitectureАрхитектура

It plugs into the loop; it does not replace itВстраивается в цикл, а не заменяет его

Extensions register tools, listen for session events, and shape the system prompt. Nothing is forked and nothing is monkey-patched: the suite is a set of modules loaded into a session.Расширения регистрируют инструменты, слушают события сессии и формируют системный промпт. Ничего не форкается и не патчится в обход: весь набор — это модули, загружаемые в сессию.

ToolsИнструменты

24 of 3324 из 33

Braid registers 24 documented tools alongside pi's 9 native ones. The full catalog lives in a single file, TOOLS.md, with each tool's enablement tier written next to it.Braid регистрирует 24 документированных инструмента рядом с 9 нативными у pi. Полный каталог живёт в одном файле TOOLS.md, а рядом с каждым инструментом указан уровень его включения.

PromptПромпт

One guideline per toolОдна директива на инструмент

Each enabled tool contributes a one-line guideline to the system prompt. A lockstep test keeps those lines exactly equal to the catalog; change one side alone and the build fails.Каждый включённый инструмент добавляет в системный промпт одну строку-директиву. Lockstep-тест удерживает эти строки в точном соответствии с каталогом: изменишь одну сторону — сборка падает.

LoadingЗагрузка

28 modules, three tiers28 модулей, три уровня

Every module is always-on, default-on, or opt-in: 7, 19, and 2 in those tiers. Always-on modules cannot be disabled; opt-in ones stay dark until a setting asks for them.Каждый модуль — always-on, default-on или opt-in: 7, 19 и 2 по уровням. Always-on модули нельзя отключить; opt-in остаются тёмными, пока настройка их не включит.

SteeringУправление

Whispers, not rewritesШёпот, а не перезапись

Mid-session feedback arrives as short injected messages that steer the next turn, without rewriting the system prompt underneath the session.Обратная связь посреди сессии приходит короткими инъекциями, которые направляют следующий шаг, не переписывая системный промпт под сессией.

07 InjectionИнъекция

Whispers at the edge of a turnШёпот на границе шага

A whisper is a short message injected into a live session. The agent sees it on its next turn; the terminal shows it; the transcript keeps it. Delivery is best-effort and flood-safe, so a whisper can never block the turn it observes.Шёпот — короткое сообщение, инжектируемое в живую сессию. Агент видит его на следующем шаге; терминал показывает; транскрипт сохраняет. Доставка — best-effort и устойчива к флуду, поэтому шёпот никогда не блокирует шаг, за которым наблюдает.

08 CalibrationКалибровка

Tuned against flatteryНастроен против угодливости

The enforcement extension is a belief-policy engine with an unglamorous job: notice when the agent is drifting, agreeing too easily, or declaring victory early, and say so.Расширение контроля — это движок убеждений и политик с негламурной работой: замечать, когда агент уплывает, слишком легко соглашается или объявляет победу раньше времени, и говорить об этом.

Structured signalsСтруктурированные сигналы

Three levels: L1 signals surface through the prompt builder, L2 bundles session-level sub-signals, and L3 marks the critical ones: validation failures and orphan chains. Chosen by policy rather than mood.Три уровня: сигналы L1 всплывают через сборщик промпта, L2 объединяет подсигналы уровня сессии, а L3 отмечает критичные: провалы валидации и осиротевшие цепочки. Выбираются политикой, а не настроением.

Sycophancy detectionОбнаружение сикофантии

Contrast-based checks compare what the agent said with what the evidence supports, and flag agreement that is not grounded.Контрастные проверки сравнивают сказанное агентом с тем, что подтверждают доказательства, и помечают необоснованное согласие.

Topic driftУход от темы

Dedicated check and reset tools measure how far the current turn has wandered from the request that opened it.Специальные инструменты проверки и сброса измеряют, насколько текущий шаг отклонился от открывшего его запроса.

Verify before doneПроверь перед завершением

A reasoning-quality detector watches for instability in the agent's own conclusions and nudges verification when confidence outruns evidence.Детектор качества рассуждений следит за нестабильностью собственных выводов агента и подталкивает к верификации, когда уверенность опережает доказательства.

On task completion a reflector reviews the turn for principles and procedures worth keeping, so a session leaves behind more than its transcript.По завершении задачи рефлектор просматривает шаг в поисках принципов и процедур, которые стоит сохранить, — сессия оставляет после себя больше, чем транскрипт.

09 MemoryПамять

Three shapes of rememberingТри формы памяти

A flat log remembers what happened. Braid keeps three stores with different shapes and search semantics, plus working state that survives compaction.Плоский лог помнит, что произошло. Braid держит три хранилища разных форм с разной семантикой поиска, плюс рабочее состояние, переживающее сжатие.

semantic.json semantic memoryсемантическая память Facts, insights, patterns, preferences, and errors; tagged, linked, and weighted by importance.Факты, инсайты, паттерны, предпочтения и ошибки; с тегами, связями и весами важности.
heuristicsэвристики procedural memoryпроцедурная память Procedure rules that evolve after a success or a failure. Kept in session and applied as they prove useful.Процедурные правила, эволюционирующие после успеха или неудачи. Живут в сессии и применяются, пока приносят пользу.

Durable goals, plans, and decisions, resumable after compaction or a restart.Долговечные цели, планы и решения, переживающие сжатие и перезапуск.

Session recallМежсессионный поиск

Search across past sessions, so yesterday's reasoning is still reachable.Поиск по прошлым сессиям: рассуждения вчерашнего дня остаются доступными.

Context lifecycleЖизненный цикл контекста

Watches context pressure and proposes archiving or compaction before a limit is hit.Следит за давлением контекста и предлагает архивацию или сжатие до достижения лимита.

Capture, diff, and restore files; a return point before risky edits.Захват, diff и восстановление файлов; точка возврата перед рискованными правками.

Counts are not embedded here: the stores on disk are the only source of truth, and the memory tools read them live.Все три хранилища доступны для кросс-поиска через memory action=recall_search. Числа сюда не вшиты: единственный источник правды — хранилища на диске, а инструменты памяти читают их напрямую.

10 The fleetФлот

One orchestrator, many handsОдин оркестратор, много рук

Large work does not fit one context. Braid delegates it: the orchestrator plans and decomposes; workers run in isolated terminals and git worktrees; results come back as artifacts, not prose.Большая работа не помещается в один контекст. Braid делегирует её: оркестратор планирует и декомпозирует; воркеры работают в изолированных терминалах и git-ворктри, а результаты возвращаются артефактами, не прозой.

11 DisciplineДисциплина

Done is a claim; evidence is the proof«Готово» — утверждение; доказательство — улики

Braid's cognitive tools exist to make premature confidence expensive: think before non-trivial moves, hypothesize when a fix fails, verify before done, finalize only with the checks green.Когнитивные инструменты Braid существуют, чтобы преждевременная уверенность стоила дорого: think перед нетривиальными действиями, hypothesize когда исправление не сработало, verify до завершения, finalize только с зелёными проверками.

thinkStructured reasoning before high-stakes or hard-to-reverse decisions.Структурированное рассуждение перед рискованными или трудно обратимыми решениями.
hypothesizeRanked root-cause candidates when a first fix fails; never a vague "something broke".Ранжированные гипотезы корневых причин, когда первое исправление не сработало; никогда расплывчатое «что-то сломалось».
verify / verify_claimChecks code, reasoning, and claims against explicit criteria. Retrieved evidence outranks memory.Проверяют код, рассуждения и утверждения по явным критериям. Найденные доказательства весомее памяти.
finalizeThe done gate. It blocks on unresolved verifications.Шлюз «готово». Блокируется на нерешённых верификациях.
conflict_qaResolves contradictions between sources instead of letting both versions live.Разрешает противоречия между источниками, не давая обеим версиям сосуществовать.

A fix lives where the invariant lives: shared layers know mechanisms, never one project's names, paths, or policy.Исправление живёт там, где живёт инвариант: общие слои знают механизмы, но никогда — имена, пути или политику одного проекта.

Placement discipline, enforced by a scan of the treeДисциплина размещения, подкреплённая сканированием дерева

The scan looks for provenance leaks, domain literals, and home paths, and every implementation report must state where its change lives. Naming the layer is part of the fix.Сканирование ищет утечки происхождения, доменные литералы и домашние пути, и каждый отчёт о реализации обязан указать, где живёт его изменение. Назвать слой — часть исправления.

12 The long loopДлинный цикл

Skill adoptionАдопция навыков

skill-usage counts what was suggested, loaded, and read. 18 InstallУстановка

$ git clone https://github.com/kifirkin/pi-braid.git ~/pi-braid

    "file:~/pi-braid/packages/core",
