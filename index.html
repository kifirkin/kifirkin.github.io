02 The harnessСреда

A small core, an open surfaceМалое ядро, открытая поверхность

pi is a minimal terminal coding agent: a session loop and a handful of built-in tools, designed so that everything else arrives as an extension. Braid is one of those extensions, and a large one.pi — минимальный терминальный кодинг-агент: цикл сессии и несколько встроенных инструментов, устроенный так, что всё остальное приходит расширениями. Braid — одно из таких расширений, и немаленькое.

A small native setНебольшой нативный набор

read, write, edit, and bash sit at the center; grep, find, ls, and PowerShell round out the working set. tool_search returns deferred tools to the active list when they are needed.read, write, edit и bash — в центре; grep, find, ls и PowerShell дополняют рабочий набор. tool_search возвращает отложенные инструменты в активный список, когда они нужны.

Sessions are treesСессии — это деревья

Every turn is a node in a JSON Lines (JSONL) session file. Branch, fork, resume, and compact in place, without losing the trail that led there.Каждый шаг — узел в файле сессии JSON Lines (JSONL). Ветвление, форки, возобновление и сжатие на месте — тропа, которая привела сюда, не теряется.

Four ways in, one loopЧетыре входа, один цикл

An interactive terminal user interface (TUI), a one-shot --print, machine-readable JSON, or Remote Procedure Call (RPC) over standard input and output. A Software Development Kit (SDK) embeds the same loop in your own programs.Интерактивный терминальный интерфейс (TUI), одноразовый --print, машиночитаемый JSON или RPC (Remote Procedure Call) поверх стандартного ввода-вывода. SDK (Software Development Kit) встраивает тот же цикл в ваши программы.

Extensible by designРасширяемость по замыслу

Extensions are TypeScript modules, skills are Markdown procedures, and prompts and themes are plain files. Bundles ship as pi packages.Расширения — TypeScript-модули, навыки — Markdown-процедуры, промпты и темы — простые файлы. Собираются в pi-пакеты.

Tool inventory, pi's native ones included: packages/core/TOOLS.md.Каталог инструментов, включая нативные: packages/core/TOOLS.md.

03 PhilosophyФилософия

The shape of “No”Форма слова «нет»

pi's core says no on purpose: each no is a door an extension can walk through, and the answer is allowed to move. One of the doors below has already opened.Ядро pi говорит «нет» намеренно: каждое «нет» — дверь, в которую может войти расширение, и ответу позволено меняться. Одна из дверей ниже уже открылась.

yesдаMCPThe no became a yes: pi ships the Model Context Protocol (MCP) as a built-in extension. Servers come from mcp.json, register with pi mcp add, and their tools are named mcp__server__tool.«Нет» стало «да»: MCP (Model Context Protocol) теперь встроенное расширение pi. Серверы берутся из mcp.json, добавляются через pi mcp add, а их инструменты называются mcp__server__tool.

noнетPermission popupsThe agent does not ask before every tool call; isolation beats interruption. Run it in a container, or wire your own confirmation where it matters.Агент не спрашивает разрешения перед каждым вызовом; изоляция лучше прерывания. Запускайте в контейнере или встройте своё подтверждение там, где это важно.

noнетTODO toolsThe core ships none; a file does the job better and does not pull the model off the work.В ядре их нет: файл справляется лучше и не отвлекает модель от работы.
noнетBackground bashA watched terminal beats a background job: tmux, full observability, direct interaction.Наблюдаемый терминал лучше фонового процесса: tmux, полная наблюдаемость, прямое взаимодействие.

The positions kept from the deck's earlier generations, checked against today's pi: one flipped, the rest hold.Позиции из прежних поколений презентации, сверенные с сегодняшним pi: одна перевернулась, остальные в силе.

05 The differenceРазница

What Braid addsЧто добавляет Braid

Bare pi is a good agent with a short memory and no second opinion. Each workspace in the suite closes one of those gaps.Голый pi — хороший агент с короткой памятью и без второго мнения. Каждый воркспейс набора закрывает один из этих пробелов.

  • —Forgets past sessionsЗабывает прошлые сессии
  • —Takes your word at face valueВерит на слово
  • —A flat tool list: read, write, edit, bashПлоский список инструментов: read, write, edit, bash
  • —No self-improvement loopНет цикла самоулучшения
  • —Starts fresh every sessionНачинает с нуля каждую сессию

With BraidС Braid

  • +verify, verify_claim, hypothesize: checks before trustverify, verify_claim, hypothesize: проверки прежде доверия
  • +Cognitive tools: think, scratchpad, memory_storeКогнитивные инструменты: think, scratchpad, memory_store
  • +A worker pool: workers in worktrees, verified before mergeПул воркеров: воркеры в ворктри, проверка до слияния

None of this is pi's job: the harness stays small and the suite carries the metacognition. That division is the point, and it has a price: a longer system prompt, more moving parts to keep working, and an API that will move before it settles.Ничто из этого не входит в задачи pi: среда остаётся маленькой, а метакогницию берёт на себя набор. В этом разделении и смысл, и у него есть цена: более длинный системный промпт, больше деталей, которые надо держать в рабочем состоянии, и API, который будет меняться, прежде чем устоится.

06 ArchitectureАрхитектура

It plugs into the loop; it does not replace itВстраивается в цикл, а не заменяет его

Extensions register tools, listen for session events, and shape the system prompt. Nothing is forked and nothing is monkey-patched: the suite is a set of modules loaded into a session.Расширения регистрируют инструменты, слушают события сессии и формируют системный промпт. Ничего не форкается и не патчится в обход: весь набор — это модули, загружаемые в сессию.

ToolsИнструменты

One catalog, one fileОдин каталог, один файл

Braid registers its tools alongside pi's native ones. The full catalog lives in a single file, TOOLS.md, with each tool's enablement tier written next to it.Braid регистрирует свои инструменты рядом с нативными у pi. Полный каталог живёт в одном файле TOOLS.md, а рядом с каждым инструментом указан уровень его включения.

PromptПромпт

One guideline per toolОдна директива на инструмент

Each enabled tool contributes a one-line guideline to the system prompt. A lockstep test keeps those lines exactly equal to the catalog; change one side alone and the build fails.Каждый включённый инструмент добавляет в системный промпт одну строку-директиву. Lockstep-тест удерживает эти строки в точном соответствии с каталогом: изменишь одну сторону — сборка падает.

LoadingЗагрузка

Three enablement tiersТри уровня включения

Every module is always-on, default-on, or opt-in. Always-on modules cannot be disabled; opt-in ones stay dark until a setting asks for them. The manifest, not the docs, is the list.Каждый модуль — always-on, default-on или opt-in. Always-on модули нельзя отключить; opt-in остаются тёмными, пока настройка их не включит. Список задаёт манифест, а не документация.

SteeringУправление

Whispers, not rewritesШёпот, а не перезапись

Feedback arrives as short injected messages that steer the next turn, never as a rewrite of the prompt under a running session.Обратная связь приходит короткими инъекциями для следующего шага, а не переписыванием промпта под работающей сессией.

07 InjectionИнъекция

Whispers at the edge of a turnШёпот на границе шага

A whisper is a short message injected into a live session. The agent sees it on its next turn; the terminal shows it; the transcript keeps it. Delivery is by class: “live” reaches the running loop, “park” is held for the end-of-turn flush, and only a genuinely critical whisper starts a new turn.Шёпот — короткое сообщение, инжектируемое в живую сессию. Агент видит его на следующем шаге; терминал показывает; транскрипт сохраняет. Доставка — по классу: «live» доходит до работающего цикла, «park» откладывается до конца шага, и только по-настоящему критичный шёпот может начать новый шаг.

Delivery class is the control. An advisory whisper rides the running turn or parks until it ends; only a genuinely critical one may start a new turn. Without that split, observation feeds itself: compaction invites a turn, a turn spends context, context invites compaction.Класс доставки и есть управление. Без этого разделения наблюдение кормит само себя: сжатие вызывает шаг, шаг тратит контекст, контекст вызывает сжатие.

09 CalibrationКалибровка

Tuned against flatteryНастроен против угодливости

The enforcement extension is a belief-policy engine with an unglamorous job: notice when the agent is drifting, agreeing too easily, or declaring victory early, and say so.Расширение контроля — это движок убеждений и политик с негламурной работой: замечать, когда агент уплывает, слишком легко соглашается или объявляет победу раньше времени, и говорить об этом.

Structured signalsСтруктурированные сигналы

Three levels: L1 signals surface through the prompt builder, L2 bundles session-level sub-signals, and L3 marks the critical ones: validation failures and orphan chains. Chosen by policy rather than mood.Три уровня: сигналы L1 всплывают через сборщик промпта, L2 объединяет подсигналы уровня сессии, а L3 отмечает критичные: провалы валидации и осиротевшие цепочки. Выбираются политикой, а не настроением.

Sycophancy detectionОбнаружение сикофантии

The classifier scores validation before correction after the reply is sent; the whisper steers the next turn, not the last one.Классификатор оценивает одобрение прежде исправления уже после отправки ответа; шёпот правит следующий шаг, а не прошлый.

Topic driftУход от темы

Dedicated check and reset tools measure how far the current turn has wandered from the request that opened it.Специальные инструменты проверки и сброса измеряют, насколько текущий шаг отклонился от открывшего его запроса.

Verify before doneПроверь перед завершением

A reasoning-quality detector watches for instability in the agent's own conclusions and nudges verification when confidence outruns evidence.Детектор качества рассуждений следит за нестабильностью собственных выводов агента и подталкивает к верификации, когда уверенность опережает доказательства.

When a task completes, a reflector reads the turn for principles and procedures worth keeping, so a session leaves more behind than its transcript.По завершении задачи рефлектор читает шаг в поисках принципов и процедур, которые стоит сохранить: сессия оставляет больше, чем транскрипт.

10 MemoryПамять

Three shapes of rememberingТри формы памяти

A flat log remembers what happened. Braid keeps three stores with different shapes and search semantics, plus working state that survives compaction.Плоский лог помнит, что произошло. Braid держит три хранилища разных форм с разной семантикой поиска, плюс рабочее состояние, переживающее сжатие.

episodes.jsonl episodic memoryэпизодическая память What happened, in what context, with what outcome. Case-based recall for the next attempt.Что случилось, в каком контексте, с каким исходом. Поиск по прецедентам для следующей попытки.
semantic.json semantic memoryсемантическая память Facts, insights, patterns, preferences, and errors; tagged, linked, and weighted by importance.Факты, инсайты, паттерны, предпочтения и ошибки; с тегами, связями и весами важности.
heuristicsэвристики procedural memoryпроцедурная память Procedure rules that evolve after a success or a failure. Kept in session and applied as they prove useful.Процедурные правила, эволюционирующие после успеха или неудачи. Живут в сессии и применяются, пока приносят пользу.

ScratchpadScratchpad

Durable goals, plans, and decisions, resumable after compaction or a restart.Долговечные цели, планы и решения, переживающие сжатие и перезапуск.

Session recallМежсессионный поиск

Search across past sessions, so yesterday's reasoning is still reachable.Поиск по прошлым сессиям: рассуждения вчерашнего дня остаются доступными.

Context lifecycleЖизненный цикл контекста

Watches context pressure and proposes archiving or compaction before a limit is hit.Следит за давлением контекста и предлагает архивацию или сжатие до достижения лимита.

Workspace snapshotСнимки workspace

Capture, diff, and restore files; a return point before risky edits.Захват, diff и восстановление файлов; точка возврата перед рискованными правками.

All three stores are cross-searchable through memory action=recall_search; the stores on disk are the only source of truth, and the tools read them directly.Все три хранилища доступны для кросс-поиска через memory action=recall_search; единственный источник правды — хранилища на диске, и инструменты читают их напрямую.

11 The worker poolПул воркеров

Large work does not fit one context. Braid делегирует её: оркестратор планирует и декомпозирует, воркеры работают в терминальных панелях и git-ворктри, а результаты возвращаются артефактами, не прозой.

12 DisciplineДисциплина

Done is a claim; evidence is the proof«Готово» — утверждение; доказательство — улики

Braid's cognitive tools make premature confidence expensive: think before a non-trivial move, hypothesize when a fix fails, verify before done, finalize only with the checks green.Когнитивные инструменты Braid делают преждевременную уверенность дорогой: think перед нетривиальным действием, hypothesize когда исправление не сработало, verify до завершения, finalize только с зелёными проверками.

thinkStructured reasoning before high-stakes or hard-to-reverse decisions.Структурированное рассуждение перед рискованными или трудно обратимыми решениями.
hypothesizeRanked root-cause candidates when a first fix fails, never "something broke".Ранжированные гипотезы корневых причин, когда первое исправление не сработало, а не «что-то сломалось».
verify / verify_claimCheck code, reasoning, and claims against explicit criteria; retrieved evidence outranks memory.Проверяют код, рассуждения и утверждения по явным критериям; найденные доказательства весомее памяти.
finalizeThe done gate. It blocks on unresolved verifications.Шлюз «готово». Блокируется на нерешённых верификациях.

A fix lives where the invariant lives: shared layers know mechanisms, never one project's names, paths, or policy.Исправление живёт там, где живёт инвариант: общие слои знают механизмы, но никогда — имена, пути или политику одного проекта.

13 The long loopДлинный цикл

It iterates on itselfОн итерирует сам себя

Beyond the turn, there is a slower loop: measure what got used, reflect on what happened, and turn failures into procedures.За пределами шага есть более медленный цикл: измерять, что было использовано, рефлексировать о случившемся и превращать провалы в процедуры.

Skill adoptionАдопция навыков

skill-usage counts what was suggested, loaded, claimed, and actually read. It is the instrument that keeps the skill library honest about what earns its place.skill-usage считает, что было предложено, загружено, заявлено использованным и действительно прочитано. Это инструмент, который не даёт библиотеке навыков обманывать себя насчёт того, что оправдывает своё место.

New skillsНовые навыки

meta-improvement creates and revises skills, runs self-improving experiments, and measures whether they helped.meta-improvement создаёт и пересматривает навыки, запускает самоулучшающиеся эксперименты и измеряет, помогли ли они.

ConsolidationКонсолидация

Heuristic evolution, offline consolidation, and Standard Operating Procedure (SOP) extraction run off the back of completed work.Эволюция эвристик, офлайн-консолидация и извлечение стандартных операционных процедур (SOP) работают по итогам завершённой работы.

Failures feed this loop passively: the evolver collects failure signatures, mines them into weakness clusters, and whispers back a summary with the actionable ones counted. Он сообщает; что менять — решает агент.

19 InstallУстановка

A command, not a buildКоманда, а не сборка

pi has to exist first; then Braid is one package install, recorded in pi's own settings. A checkout is for working on Braid, not for using it.Сначала — pi. Затем Braid — это одна установка пакета, и pi записывает её в свои настройки. Клон — чтобы работать над Braid, а не пользоваться им.

# pi, the harness# pi, среда
$ npm install -g --ignore-scripts @earendil-works/pi-coding-agent

# braid, then the add-ons you want# braid, затем нужные надстройки
$ pi install npm:pi-braid
$ pi install npm:pi-braid-skills

# first run: connect a provider# первый запуск: подключите провайдера
$ pi   # then /login inside the session# затем /login внутри сессии

    "file:~/pi-braid/packages/core",
